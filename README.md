# period-diary · 经期记

fnOS(飞牛OS)经期记录应用:一键标记经期开始/结束,自动预测下次经期、排卵日与易孕期,附周期统计图表;只记日期,不采集经量/症状/心情。按飞牛账户隔离,数据只存本机不上云,免费无广告无会员。

> 本仓库仅存放使用文档与安装包;应用以 fpk 安装包形式发布,不含源码。

## 功能特性

- 🌸 **一键标记**:点击日历日期即可标记「经期开始 / 经期结束」,重叠记录自动合并;也可在「手动记录」里用日历弹层选择起止日期
- 🏷️ **始末标志**:日历在每次经期第一天标「始」、最后一天标「末」,一眼看清每次区间
- 📅 **自动预测**:以最近一次经期结束日 + 28 天推算下次经期,并推算易孕期与排卵日,在日历上着色显示(均为估算,界面有提示)
- 📊 **周期统计**:平均周期、经期时长、最短/最长周期、波动程度与近期趋势图
- 🗂 **历史记录**:每条记录独立卡片,含开始时间、结束时间与总时长;删除需二次确认
- 🔔 **友好提示**:日期选择用日历组件,操作提示统一为应用内 toast,不弹浏览器原生对话框
- 🔒 **本地存储**:SQLite 按飞牛账户分库,数据不出本机

## 安装(飞牛OS)

1. 从 [Releases](../../releases) 下载对应架构的 fpk:
   - `period-diary-x86-<版本>.fpk` — Intel/AMD(x86_64)设备
   - `period-diary-arm-<版本>.fpk` — ARM(arm64)设备
2. 飞牛OS 桌面 → **应用中心** → 手动安装,上传 fpk
3. 安装完成后从桌面打开「经期记」即可使用

## 使用说明

- **记录经期**:点击日历上的日期,在弹出的操作条里选「经期开始」(自动按平均经期时长补结束日)或「经期结束」;两次记录重叠时会自动合并
- **手动记录**:左侧「手动记录」卡片中点开开始/结束字段(日历弹层)选好区间 →「保存记录」
- **删除记录**:日历操作条里的「删除本次」或历史记录里的「删除」都会先弹二次确认
- **查看预测**:有记录后,顶部卡片显示「距离下次经期」天数与预计日期;日历上虚线圆为预测经期、紫色为易孕期/排卵日,仅供参考

## 应用架构(简介)

```
飞牛OS 桌面(iframe)
   │  统一网关 /app/period-diary(unix socket app.sock,身份注入 X-Trim-Userid)
   ▼
fnOS 应用包(无任何外部服务)
   ├─ Go 后端:经期记录 CRUD + 前端静态文件;SQLite 按 uid 分库存 TRIM_PKGVAR
   └─ React 前端:日历标记、预测、统计图表、历史列表
```

纯本地应用:没有云端、没有账号系统、没有对外网络请求;同机不同飞牛账户的数据互相隔离。

## 隐私说明

应用只记录日期,不采集经量、症状、心情等任何其他信息;所有数据保存在本机 SQLite 中,按飞牛账户隔离,无云端同步、无统计上报、无广告与第三方追踪。
